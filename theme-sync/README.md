# theme-sync

GNOME dark style → **Vesper**. GNOME light style → **Flexoki Light**.
Flip it from Quick Settings ("Dark Style"), Settings → Appearance, or `theme-sync toggle`.

## How it works

Apps that already follow the system's light/dark setting are configured once and switch on their own:

| App | Mechanism |
| --- | --- |
| ghostty | `theme = light:Flexoki Light,dark:Vesper` |
| kitty | `{dark,light,no-preference}-theme.auto.conf` |
| herdr | `[theme] auto_switch = true` |
| vicinae | `theme.light` / `theme.dark` in settings.json |
| yazi | `[flavor] dark/light` (picked at startup) |
| GTK4 / libadwaita | `@media (prefers-color-scheme)` in `~/.config/gtk-4.0/gtk.css` |
| Discord (Vencord) | `@media (prefers-color-scheme)` in QuickCSS |
| VS Code | `window.autoDetectColorScheme` |

Everything else is handled by `bin/theme-sync --watch`, which runs as the
`theme-sync.service` systemd user unit. It watches
`org.gnome.desktop.interface color-scheme` and switches:

- GTK3 theme, icon theme and GNOME Shell theme (`Vesper` / `Flexoki-Light` user theme)
- dash-to-panel and p7-borders colors, rounded-window-corners shadows (softer in light mode)
- GTK3 `gtk.css`, gitui, lazygit, btop (these take effect the next time each app starts)
- tmux, which is re-sourced live in every running server
- Claude Code: `settings.json` is pinned to the custom theme `custom:rice`, and
  `~/.claude/themes/rice.json` is re-pointed at `claude/<mode>.json`. Claude watches that
  folder, so running sessions switch live.
- Codex: `[tui] theme` in `~/.codex/config.toml` is set to `vesper` / `flexoki-light`
  (`.tmTheme` files in `~/.codex/themes`). This applies to new Codex sessions.
- `~/.local/state/theme-sync/mode`, which nvim watches so it switches live, which zsh (syntax-highlighting colors) checks before each prompt

## Files

- `vesper/`, `flexoki-light/`: per-mode app themes. The light files are generated with
  `gen/remap.py vesper <vesper-file> <out>`.
- `gnome-shell-Flexoki-Light/`: generated with `gen/remap.py shell /usr/share/themes/Yaru/gnome-shell/gnome-shell.css`,
  then the notification-card, vertical-clock and light-panel tweaks are added at the end.
  Symlinked to `~/.local/share/themes/Flexoki-Light`.
- `tmux/`: status bar palettes, sourced through `~/.local/state/theme-sync/tmux.conf`.
- `claude/`: Claude Code themes (`{name, base, overrides}`; keys are Claude's theme color names).
- `codex/`: Codex syntax themes, generated by `gen/tmtheme.py`. Edit the palettes there and rerun it.
- `lazygit-base.yml`: non-theme lazygit config. `~/.config/lazygit/config.yml` is generated from it.

## Install on a fresh machine

```sh
ln -sfn ~/dotfiles/theme-sync/bin/theme-sync ~/.local/bin/theme-sync
ln -sfn ~/dotfiles/theme-sync/systemd/theme-sync.service ~/.config/systemd/user/
ln -sfn ~/dotfiles/theme-sync/gnome-shell-Flexoki-Light ~/.local/share/themes/Flexoki-Light
mkdir -p ~/.codex/themes && ln -sfn ~/dotfiles/theme-sync/codex/*.tmTheme ~/.codex/themes/
systemctl --user enable --now theme-sync.service
```

The Vencord QuickCSS master copy is `vencord-quickCss.css`, and the GTK4 one is `gtk4.css`.
